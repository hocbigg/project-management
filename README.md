## How to use this curriculum

### Core Sections

Study them **in this exact order** to build knowledge step by step:

I. Foundations of Project Management  

II. Project Initiation & Definition  

III. Project Planning & Baselines  

IV. Risk, Quality, and Procurement  

V. Execution, Monitoring & Control  

VI. Project Closure & Organizational Learning  

VII. Human & Communication Dimensio

### Specialization Tracks

After completing the Core (sections I–VII), you can choose one or more of the following three sections depending on your goals:

- VIII. Project Management Methodologies (Comparative): Choose this if you want to understand different ways projects can be managed (traditional, agile, hybrid, etc.) and when to use each.
- IX. Governance, Programs & Portfolios: Choose this if you are interested in how multiple projects are coordinated at the organizational level, or if you aim for roles in program management, portfolio management, or PMO leadership.
- X. Advanced & Contextual Topics (Electives): Choose this if you want exposure to modern trends (sustainability, data-driven project management) or real-world industry examples.
